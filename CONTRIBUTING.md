# 如何提交 / How to contribute

## 客户（推荐）

1. 先阅读 [安装要求](README.md#requirements)。
2. 打开 [提交表格](https://github.com/noron-official/noron-display-compatibility/issues/new?template=report.yml)。
3. 填写购买国家、商店、品牌型号、VESA、厚度、出线位置、游戏模式和结果。
4. 能拍照的话，请附上 VESA 孔、厚度和侧面接口。

提交后请等维护者核对，并写入 `data/displays.csv` 和 README 清单。

## Customers (recommended)

1. Read the [requirements](README.md#requirements) first.
2. Open the [report form](https://github.com/noron-official/noron-display-compatibility/issues/new?template=report.yml).
3. Fill in country, store, brand and model, VESA, thickness, cable-exit location, Game Mode, and the result.
4. Attach photos of the VESA holes, mount thickness, and side ports if you can.

A maintainer will review the issue and add confirmed rows to `data/displays.csv` and the README.

## 直接改文件 / Pull requests

请保持 `data/displays.csv` 为 UTF-8，不要删表头，也不要编造未实测的型号。
